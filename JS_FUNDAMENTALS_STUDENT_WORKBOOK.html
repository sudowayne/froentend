🚀 Module 0: How to Run Code & See Results Instantly

To learn JavaScript, you must see your code run in real-time. Pick either Track A (Terminal) or Track B (Chrome Console):

Track A: Terminal (Node.js)

  1. Create a folder named js-class and open it in VS Code.
  2. Create a file named app.js.
  3. Open terminal: Press Ctrl + `.
  4. Run your script anytime: 
    node app.js
  5. Output appears directly inside your terminal!

Track B: Chrome DevTools Console

  1. In the same folder, create index.html.
  2. Link your script: 
    <script src="app.js"></script>
  3. Open index.html in Chrome.
  4. Press F12 → click Console.
  5. Every time you save and refresh (Ctrl + R), output appears!

📦 Module 1: Variables & Data Types

💡 The Jar Analogy:
  • const = Sealed Jar. Once you put data inside, you cannot reassign it. (Use 90% of the time).
  • let = Open Jar. Contents can change (e.g. counters, scores, running totals).
  • var = Old broken jar from 1995. Never use it in modern JavaScript.
// ── 1. Declaring Variables ───────────────────
const schoolName = "Apex Tech Academy"; // Sealed jar
let studentCount = 30;                 // Open jar

console.log("School:", schoolName);
console.log("Initial Students:", studentCount);

// ── 2. Updating Variables ────────────────────
studentCount = 35; // Allowed because it's 'let'
console.log("Updated Students:", studentCount);

// ── 3. Checking Types ────────────────────────
const studentAge = 21;
const isEnrolled = true;
const graduationYear = null;

console.log("Type of schoolName:", typeof schoolName);
console.log("Type of studentAge:", typeof studentAge);
console.log("Type of isEnrolled:", typeof isEnrolled);
🖥️ Expected Terminal / Console Output:
School: Apex Tech Academy Initial Students: 30 Updated Students: 35 Type of schoolName: string Type of studentAge: number Type of isEnrolled: boolean
🧪 Break It & Fix It: Add schoolName = "New Academy"; and run your file. Observe the red TypeError: Assignment to constant variable. This proves const protects your data.

🚪 Module 2: Conditionals & Logical Operators

💡 The Bouncer Analogy: Conditionals act like a nightclub security guard.
  • if = If you have a VIP ticket, walk in.
  • else if = If you're on the regular guestlist, walk in.
  • else = Otherwise, go home.
  • && (AND): Both conditions must be true. | || (OR): At least one must be true.
// ── 1. If / Else If / Else ───────────────────
const score = 82;

if (score >= 90) {
  console.log("Grade: A - Outstanding!");
} else if (score >= 75) {
  console.log("Grade: B - Very Good!");
} else if (score >= 50) {
  console.log("Grade: C - Pass");
} else {
  console.log("Grade: F - Try Again");
}

// ── 2. Logical Operators (&& and ||) ─────────
const age = 19;
const hasValidID = true;

if (age >= 18 && hasValidID) {
  console.log("Access Granted: Welcome to the Exam Hall 🎓");
} else {
  console.log("Access Denied: Missing requirements ❌");
}

// ── 3. Ternary Operator (One-Liner If/Else) ──
const attendance = 85;
const status = attendance >= 75 ? "ELIGIBLE" : "BARRED";
console.log("Exam Clearance:", status);

// ── 4. Nullish Coalescing (??) Fallback ─────
const customNickname = null;
const displayName = customNickname ?? "Student";
console.log("Hello,", displayName);
🖥️ Expected Terminal / Console Output:
Grade: B - Very Good! Access Granted: Welcome to the Exam Hall 🎓 Exam Clearance: ELIGIBLE Hello, Student

🍳 Module 3: Functions (The 3 Styles & Return Values)

💡 The Recipe Analogy: A function is a recipe card.
  • Parameters: The ingredients passed in.
  • Logic: The cooking process.
  • Return: Serving the meal. If you omit return, JavaScript serves undefined!
// ── 1. Function Declaration (Classic) ────────
function calculateDiscount(price, discountPercent) {
  const savings = (price * discountPercent) / 100;
  return price - savings;
}
console.log("Discounted Price:", calculateDiscount(100, 20));

// ── 2. Function Expression ───────────────────
const checkPass = function (mark) {
  return mark >= 50 ? "PASS" : "FAIL";
};
console.log("Exam Result:", checkPass(68));

// ── 3. Modern Arrow Function (React Standard) 
const formatInvoice = (customerName, total) => {
  return `Receipt for ${customerName}: Total Due = $${total}`;
};
console.log(formatInvoice("Ameen", 150));

// ── 4. Default Parameters ────────────────────
const greetUser = (name = "Guest") => {
  return `Welcome, ${name}!`;
};
console.log(greetUser());         // Uses default
console.log(greetUser("Kemi"));   // Overrides default
🖥️ Expected Terminal / Console Output:
Discounted Price: 80 Exam Result: PASS Receipt for Ameen: Total Due = $150 Welcome, Guest! Welcome, Kemi!

🏃 Module 4: Loops & Repetition

💡 The Track Runner Analogy: If your coach says "do 5 laps", you don't build 5 tracks; you run the same track 5 times until the whistle blows.
  • for: When you know the exact lap count.
  • while: Keep running as long as a condition is true.
  • for...of: The modern way to visit every item in an array cleanly.
  • break: Emergency brake (stops the loop). | continue: Skip this single turn.
// ── 1. Classic for Loop (Counting Laps) ──────
for (let lap = 1; lap <= 3; lap++) {
  console.log(`Lap ${lap} completed 🏃`);
}

// ── 2. while Loop (Charging Battery) ─────────
let battery = 85;
while (battery < 100) {
  battery += 5;
  console.log(`Charging... Battery at ${battery}% 🔋`);
}
console.log("Battery Full! ⚡");

// ── 3. break & continue ─────────────────────
for (let seat = 1; seat <= 4; seat++) {
  if (seat === 2) {
    console.log(`Seat ${seat} is RESERVED (skipping)`);
    continue; // skips 2
  }
  console.log(`Passenger seated at Seat ${seat}`);
}

// ── 4. Modern for...of Loop ─────────────────
const courses = ["HTML", "CSS", "JavaScript", "React"];
for (const course of courses) {
  console.log("Enrolled in:", course);
}

Battery at 100% 🔋 Battery Full! ⚡ Passenger seated at Seat 1 Seat 2 is RESERVED (skipping) Passenger seated at Seat 3 Passenger seated at Seat 4 Enrolled in: HTML Enrolled in: CSS Enrolled in: JavaScript Enrolled in: React

📚 Module 5: Arrays & The Big 4 Array Methods

💡 The Numbered Shelf Analogy: Arrays start at index 0.
  • .forEach(): Visit each shelf and do something. (No return).
  • .map(): Transform each item into a new array. (The King of React!).
  • .filter(): Keep only items that pass your test.
  • .find(): Return the first single match.
const scores = [45, 82, 95, 30, 68, 77];

// 1. forEach — Log each item
scores.forEach((score, index) => {
  console.log(`Student ${index + 1}: ${score}`);
});

// 2. map — Curve scores by adding 5 bonus marks
const curvedScores = scores.map((score) => score + 5);
console.log("Curved Scores:", curvedScores);

// 3. filter — Keep only passing scores (>= 50)
const passingScores = scores.filter((score) => score >= 50);
console.log("Passing Scores:", passingScores);

// 4. find — Grab the first distinction (>= 90)
const distinction = scores.find((score) => score >= 90);
console.log("First Distinction:", distinction);

// 5. Spread Operator (...) — Copy without mutating
const squadA = ["Ameen", "Kemi"];
const squadB = [...squadA, "Tunde"];
console.log("New Squad:", squadB);
🖥️ Expected Terminal / Console Output:
Student 1: 45 Student 2: 82 Student 3: 95 Student 4: 30 Student 5: 68 Student 6: 77 Curved Scores: [ 50, 87, 100, 35, 73, 82 ] Passing Scores: [ 82, 95, 68, 77 ] First Distinction: 95 New Squad: [ 'Ameen', 'Kemi', 'Tunde' ]

🪪 Module 6: Objects, Destructuring & Optional Chaining

💡 The Student ID Card Analogy: Objects store data in named key-value pairs.
  • Destructuring: Unpack properties directly (const { name, age } = student).
  • Optional Chaining (?.): Safely access nested fields without crashing.
  • Arrays of Objects: The industry-standard format for database and API data!
// ── 1. Object Literal ────────────────────────
const student = {
  id: 101,
  name: "Ameen Wasiu",
  age: 22,
  course: "Fullstack Engineering",
  contact: { email: "ameen@apextech.com", phone: null }
};

// ── 2. Destructuring ─────────────────────────
const { name, course } = student;
console.log(`Student ${name} is enrolled in ${course}`);

// ── 3. Optional Chaining (?.) & Fallback (??) 
const city = student.address?.city ?? "City Not Specified";
console.log("Location:", city);

// ── 4. Arrays of Objects ─────────────────────
const students = [
  { id: 1, name: "Ameen", score: 85, active: true },
  { id: 2, name: "Kemi", score: 92, active: true },
  { id: 3, name: "John", score: 40, active: false }
];

const activePassed = students.filter((s) => s.active && s.score >= 50);
console.log("Active Passed Count:", activePassed.length);

const foundStudent = students.find((s) => s.id === 2);
console.log("Found Student Name:", foundStudent?.name);
🖥️ Expected Terminal / Console Output:
Student Ameen Wasiu is enrolled in Fullstack Engineering Location: City Not Specified Active Passed Count: 2 Found Student Name: Kemi
